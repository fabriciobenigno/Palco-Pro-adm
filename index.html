Fluxo correto

Use sempre esta sequência para atualizar as sugestões do aplicativo principal.

Manual
1. Vincule o catalogo.json da pasta do projeto (ou anexe o arquivo).
2. Edite, cadastre, exclua, desative ou altere o estilo de várias músicas.
3. Com o arquivo vinculado, as alterações são gravadas automaticamente no catalogo.json.
4. Se o navegador não permitir gravação direta, use Baixar catalogo.json atualizado e substitua o arquivo manualmente.

Contexto do projeto

Notas permanentes para manter este painel e futuras alterações alinhados com o projeto.

Palco Pro

Aplicativo principal: Palco Pro, voltado para músicos, com aparência de teleprompter.

Repertório pessoal: armazenado localmente no dispositivo do usuário. Não depende de conta ou Supabase.

Teleprompter: a letra desliza continuamente como um teleprompter, sem destaque individual de estrofe.

Backup: o app principal possui exportação/importação do repertório pessoal.

Reconhecimento por fala: mantido no projeto, mas temporariamente desativado no principal.

Catálogo de sugestões: este painel edita o arquivo catalogo.json. Quando a pasta do projeto é vinculada, o arquivo pode ser gravado diretamente no mesmo diretório do projeto.

Regra: não reintroduzir Supabase, usuários, sincronização por conta, tokens ou GitHub Actions no fluxo do catálogo.
