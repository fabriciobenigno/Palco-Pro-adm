Contexto do projeto

Notas permanentes para manter este painel e futuras alterações alinhadas com o projeto.

Palco Pro

Aplicativo principal: Palco Pro, voltado para músicos, com aparência de teleprompter.

Repertório pessoal: armazenado localmente no dispositivo do usuário. Não depende de conta ou Supabase.

Teleprompter: a letra desliza continuamente como um teleprompter, sem destaque individual de estrofe.

Backup: o app principal possui exportação/importação do repertório pessoal.

Reconhecimento por fala: mantido no projeto, mas temporariamente desativado no principal.

Catálogo de sugestões: este painel edita o arquivo catalogo.json. O catálogo principal é carregado e atualizado pelo Apps Script; a importação/exportação manual continua disponível.

Regra: não reintroduzir Supabase ou sincronização do repertório pessoal. A publicação administrativa do catalogo.json é feita pelo Apps Script autorizado.
